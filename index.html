Baseball ML: Team Wins & Hall of Fame

PyTorch models exported to ONNX and run fully in your browser with onnxruntime-web. The models apply their own feature standardization, so type in raw values.

1 · Regression: MLB Team Wins

Model: PyTorch network (linear + nonlinear parts) trained with MSE loss on full 162-game seasons, 1962–2021 (Lahman Database).

2 · Classification: Baseball Hall of Fame

Model: PyTorch neural network trained with cross-entropy loss on career batting stats (Lahman Database). Output is softmax probability.

Models: wins_regression.onnx · hof_classifier.onnx · Input name input1 [batch, 8] → output output1
